WHAT THIS REPOSITORY IS
===============================================================================

This repository provides PORTABLE BINARIES of the rippled server (the core 
software that powers the XRP Ledger network). These binaries work across 
multiple Linux distributions without requiring compilation from source.

Primary Functions:
1. Binary Distribution - Provides verified, signed rippled binaries
2. Security Verification - Ensures all binaries are cryptographically signed
3. Documentation - Guides for installation and troubleshooting
4. Governance - Transparent processes for repository security

HOW TO USE THIS REPOSITORY
===============================================================================

METHOD 1: INSTALL A BINARY
---------------------------
Step 1: Download files
wget https://github.com/XRPLF/rippled-portable-builds/raw/main/releases/rippled-portable-2.1.1
wget https://github.com/XRPLF/rippled-portable-builds/raw/main/releases/rippled-portable-2.1.1.sig
wget https://raw.githubusercontent.com/XRPLF/rippled-portable-builds/main/verify-binary.sh

Step 2: Verify
chmod +x verify-binary.sh
./verify-binary.sh rippled-portable-2.1.1

Step 3: Install (if verification passes)
chmod +x rippled-portable-2.1.1
sudo mv rippled-portable-2.1.1 /opt/ripple/bin/

METHOD 2: UPLOAD DOCUMENTATION
-------------------------------
Option A - Interactive Script:
./upload-document.sh
(Follow prompts)

Option B - Web Interface:
1. Go to repository on GitHub
2. Click "Issues" tab
3. Click "New Issue"
4. Select "Upload Documentation"
5. Paste content or drag-and-drop files
6. Submit

Option C - Manual Upload:
1. Fork repository
2. Add files to docs/ subdirectories
3. Commit and push
4. Create pull request

METHOD 3: REVIEW SECURITY
--------------------------
Run security audit:
./audit-repository.sh

Review security policy:
cat SECURITY.md

Check governance:
cat GOVERNANCE.md

GPG VERIFICATION PROCESS
------------------------
Every binary must:
1. Come from official XRPLF source
2. Have valid GPG signature
3. Match expected fingerprint: 6D70 4017 0DEA 4F69 DEF5 D569 B6F9 7CF2 1A96 2003
4. Pass checksum verification (when available)
